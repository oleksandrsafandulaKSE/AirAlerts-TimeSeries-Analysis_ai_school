### 2.1 The offset, exactly
- Causal recent rate r(t) = (k + 10·q(t)) / (n + 10) over unmasked rows of the unit with known labels in
  [t − 14 d, t − H] (D-025 form), where the prior q(t) is the unit's EXPANDING onset rate over all its eligible rows with
  s ≤ t − H since the grid start (not the full-train `p_unit`, which would leak later outcomes into early training rows and
  into backtest folds). If the unit has no such row yet, q(t) = the national expanding rate; if that is undefined the row is
  dropped (counted).
- offset(t) = logit(clip(r(t), 1e-4, 1 − 1e-4)) for EVERY row: fit, early-stopping, validation, test.
- Training: `lgb.Dataset(..., init_score=offset)` for fit and early-stopping sets. Prediction:
  p(t) = sigmoid(offset(t) + booster.predict(X, raw_score=True)). Saved model + offset function reproduce validation
  predictions exactly after reload (test). Oracle test: a booster forced to zero residual (0 trees) returns clip(r(t), 1e-4, 1 − 1e-4) exactly, incl. the
  endpoint cases r = 0 → 1e-4 and r = 1 → 1 − 1e-4;
  a future-label perturbation test alone is not enough. The single "best post-hoc" row = the variant with the lowest VALIDATION
Brier among V2, V3, V5 (V1/V4 have no common validation set and are reported as they are).

## 3. Candidate feature blocks ("logical patterns"), all computable at t
- **A. Drift:** the unit's shrunk recent rate over 14 d and 30 d (labels known at t: s ≤ t − H), national recent rate 14 d.
- **B. Waves:** national onsets in (t − 1h, t] and (t − 3h, t]; frontline onsets in (t − 3h, t] (attacks often start in
  the east/south and move west); neighbours' onsets in (t − 1h, t]; time since the last national onset.
- **C. Periodicity:** the unit had an onset in [t − 25 h, t − 23 h] (same time yesterday); count of onsets in the same
  Kyiv hour ±1 over the last 7 days.
- Gap rules: identical to D-023 (any window touching the uncertainty zone → NaN; D-024 then drops the row).
**Exact definitions:** onsets (blocks B and C) = D-023 merged onsets. "Same time yesterday" is defined in UTC: an onset in [t − 25 h, t − 23 h]. "Same Kyiv
hour ±1 over 7 days" = onsets whose Kyiv local hour is within ±1 of t's Kyiv hour (mod 24, so 23 ↔ 0 wraps), counted over
(t − 7 d, t]; local hours come from converting each onset's UTC time (a repeated DST hour is just two UTC instants).
Label-based rates use k = sum(y) and n = count(y) over ELIGIBLE rows (unmasked, label known, s ≤ t − H), with y the
binary label of `grid.build_grid` (≥ 1 onset in the horizon counts once). Unit rates (14 d, 30 d, the offset's r(t)) are
SHRUNK: (k + 10·q(t)) / (n + 10) with the causal prior q(t) of §2.1; the expanding prior q(t) itself and the national 14-d
rate are pooled, UNSHRUNK proportions k / n (national = k and n summed over all units). Too little history (window before the grid start) → NaN → row dropped by
D-024 (counted).
**Acceptance (no validation or test labels involved):** rolling-origin backtest INSIDE train: 4 folds with cut-offs
2025-07-01, 2025-10-01, 2026-01-01, 2026-04-01; each fold fits on rows with t + H ≤ cut-off − 14 d, early-stops on rows in
[cut-off − 14 d, cut-off) with t + H ≤ cut-off, scores [cut-off, cut-off + 8 weeks) (inside train). The offset prior is
causal (§2.1), so no fold sees later outcomes. Greedy, fixed order A, B, C: the candidate = current accepted set + block;
the reference = current accepted set (starting from V2). Both are scored on IDENTICAL keys per fold (rows where every
candidate feature is known); accept iff the equal-weighted mean of the 4 fold Briers drops by ≥ 0.5 % RELATIVE and the
fold Brier drops in ≥ 3 of 4 folds; ties reject. Every block's fold results are reported, accepted or not.
V2 / V3 / V5 validation selection is also done on identical keys (rows where V3's features are known).

## 5. Leakage
- Every new feature joins the truncation test on real data (same 33 times, raw-data truncation) with a negative control
  per block, each caught at a PINNED witness (a time and unit where the leak provably changes the value): A: rate window
  reading s ≤ t; B: wave count over (t − 3h, t + 1h]; C: "same time tomorrow".
- Expected-value fixtures (hand-computed) for every new feature at: both 2025 DST switches (incl. the ±1-hour wraparound
  23 ↔ 0), the exact gap-zone boundaries (D-023: NaN inside, number after), an alert with unknown `finished_at` and an
  alert hitting the 24 h cap (merged onsets unchanged), and separate Kyiv City / Kyivska membership in the wave and
  neighbour counts.
- The offset: recent rate at t uses s ≤ t − H only (existing tested function); test that flipping labels with
  s > t − H leaves every V2/V3 prediction unchanged.
- Weekly refit: each step's fit/early-stopping keys end before its cut-off (exact-keys test, H = 1), and flipping
  labels at or after C leaves that step's model unchanged.
